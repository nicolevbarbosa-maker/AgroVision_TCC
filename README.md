# 🌱 AgroVision

Sistema de agricultura de precisão desenvolvido como Trabalho de Conclusão de Curso em Tecnologia da Informação.

## 📌 Sobre o projeto

O AgroVision utiliza visão computacional e inteligência artificial
para auxiliar no monitoramento de plantações.

O sistema busca identificar possíveis pragas, doenças e anomalias
nas plantas por meio da análise de imagens capturadas por uma webcam
que simula a visão de um drone.

## 🎯 Objetivo

Desenvolver uma solução tecnológica capaz de auxiliar no
monitoramento de plantações e na identificação de possíveis
problemas agrícolas.

## 🚁 Funcionamento

1. A câmera realiza a captura da plantação.
2. As imagens são enviadas para o sistema.
3. A inteligência artificial analisa as imagens.
4. Possíveis anomalias são identificadas.
5. Os resultados são apresentados no painel AgroVision.

## 🧠 Inteligência Artificial

O projeto utiliza YOLO para desenvolvimento da solução
de detecção por visão computacional.
